# kakol.pro

Michał Kąkol's home page. A retro academic homepage on the surface
(Times New Roman, white page, blue links, a hit counter), modern underneath
(semantic HTML5, dark mode, RSS, sitemap, JSON-LD, a service worker, and a
command palette — press `/`). Static, hand-rolled, no framework.

Build: `python3 _build.py` (reads `content/`, emits pages + `feed.xml` + `sitemap.xml`).
Field-note sources live in `content/`.
