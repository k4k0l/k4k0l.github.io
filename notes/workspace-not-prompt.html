    The interesting unit is not the prompt. It is the workspace.

    2026-06-19 · field note · #AI #knowledge-systems #engineering #agents

    There is a whole genre of advice about prompting now: frameworks, role-play incantations, the correct way to ask a model to take a deep breath and think step by step. Most of it is true and almost none of it matters, because the prompt has the shortest half-life in the system. You write it, you get an answer, it evaporates. Nothing accumulates.

    What accumulates is the workspace: the durable, agent-readable context an organization carries with it. Not the question you ask today, but the substrate that makes tomorrow's answer worth trusting.

    I have been building one — an internal, AI-augmented knowledge system for a stack that long ago stopped fitting in any single head. The premise is unglamorous. Real knowledge is scattered across wikis nobody updates, threads nobody can find, and a few experts tired of answering the same question. The bet is that you can compress that into context an agent can read. Mechanically it isn't exotic: analyses written down instead of remembered; handoffs between sessions and people; the operational recipe that actually fixes the thing at 2am, not the idealized one from the runbook; reusable skills; and a verification gate — because an exocortex that confidently remembers wrong things is worse than none.

    None of those pieces is a prompt. The prompt is the last six inches of pipe. Everything load-bearing happens upstream, in the context the model gets to stand on. The model is the executor; I am the architect and reviewer. The same model on a thin, ad-hoc context produces fluent, plausible, occasionally catastrophic output. Standing on a well-maintained workspace, it produces something you can route to a colleague without re-checking every line.

    I won't pretend the thesis is vindicated. The system is largely aspirational and single-operator; the bus factor is roughly one. Worse, and more instructive: in at least one logged session, the retrieval layer I had carefully built went entirely unqueried. The context was present and the behavior did not change. Building the library does not mean anyone walks into it — and that is the failure mode nobody puts in the demo.

    So, plainly: if you are building with AI and spending your energy on prompt craft, you are polishing the cheapest, most disposable layer in the stack. The durable returns are in the boring infrastructure — capturing what you learn in a form an agent can read, gating it so the wrong things don't become canon, and designing for whether the context gets used, not merely whether it exists. The prompt is a sentence. The workspace is a memory. Only one is worth maintaining for years, and it isn't the sentence.
